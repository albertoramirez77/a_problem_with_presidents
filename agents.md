# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project purpose

Analyze the lifespans of the 45 people who have served as U.S. President
(see `README.md` for the full problem statement): create the variables
`year_of_birth`, `lived_years`, `lived_months` and `lived_days`, rank the
top 10 longest- and shortest-lived presidents, summarize `lived_days` with
descriptive statistics, and plot its distribution.

## Setup and run

With uv:

```bash
uv sync
uv run python presidents_analysis.py
```

Without uv: `pip install pandas numpy matplotlib tabulate`, then
`python presidents_analysis.py`.

Run from the repository root (paths are relative). A successful run prints
three Markdown tables and writes to `output/`:
`longest_lived_presidents.csv`, `shortest_lived_presidents.csv`,
`lived_days_summary_statistics.csv`, `presidents_with_lifespans.csv` and
`lifespan_distribution.png`.

## Rules

1. **Never edit the source CSV.** Data corrections go in the
   `DEATH_DATE_CORRECTIONS` dictionary in the script, with a comment explaining why.
2. **Keep the required variable names exactly:** `year_of_birth`, `lived_years`,
   `lived_months`, `lived_days`.
3. **Parse dates with `format="mixed"`.** The CSV mixes full month names
   ("July 4, 1826") with abbreviations ("Feb 22, 1732"); default parsing
   silently drops 6 birth dates.
4. **Keep `ANALYSIS_DATE` fixed.** Do not replace it with `Timestamp.today()`;
   results must be reproducible.
5. **Readability over cleverness.** The code is walked through in an interview.
   Use snake_case for variables, ALL_CAPS for constants, descriptive names,
   and comments that explain *why*.
6. **Surgical changes only.** Every change must trace back to a specific request.
   Do not refactor, reformat or add features nobody asked for.
7. **State assumptions instead of guessing.** If a request is ambiguous
   (for example, what to weight an average by), ask, or document the choice
   in a comment.

## How to verify a change

- The script runs with no errors or warnings.
- The built-in `assert` checks pass (45 presidents, all birth dates parsed,
  exactly 5 living presidents).
- Spot-check known facts: Jimmy Carter is longest-lived at 100.24 years;
  John F. Kennedy is shortest-lived at 46.48 years.
- Open `output/lifespan_distribution.png` and confirm no labels overlap.
- If any number changes, update the PDF report to match.
